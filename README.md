# Gastronomie lyonnaise

Site vitrine d'une page sur la cuisine lyonnaise : présentation, plats emblématiques (coq au vin, quenelle de brochet, salade lyonnaise) et restaurants célèbres (Paul Bocuse, Brasserie Georges).
Un de mes premiers exercices d'intégration HTML et CSS.

## Stack

HTML · CSS

## Ce que j'ai travaillé

- Structure sémantique : `nav`, `section`, `footer`
- Mise en page en cartes pour les plats et les restaurants
- Adaptation mobile avec une media query (768 px)

## Lancer le projet

Aucune installation : ouvrir `index.html` dans un navigateur.
